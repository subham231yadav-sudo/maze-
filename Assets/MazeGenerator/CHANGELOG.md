# Changelog

## [1.0.0] — Initial release

- Procedural 3D maze generation (Recursive Backtracker, Prim, Eller)
- Shapes: rectangle, circle, custom texture mask
- Post-process: openings, braiding, empty rooms
- Prefab wall builder (primary + up to 2 secondary variants with %)
- Primary wall defines spacing; secondaries fit the same size envelope
- Editor actions: Generate, Reseed, Clear, Solve debug (A*)
- Drop-in `MazeGenerator` prefab + demo scene (`MazeDemo`)
- Unity 6 + URP
